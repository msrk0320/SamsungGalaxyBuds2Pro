Galaxy Buds 2 Pro – BLE Probe

Checks what the Buds expose to an iPhone over Bluetooth LE.

How to use

  1. Install the free Bluefy browser from the App Store (Safari has no Web Bluetooth).
  2. Open this page in Bluefy.
  3. Buds in the case, lid open. If nothing shows up, long-press both touchpads (in ears) to enter pairing mode.
  4. Tap Scan, pick the Buds, then tap Copy report and send it back.
